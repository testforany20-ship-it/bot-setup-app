🤖 ব্লগ বট সেটআপ

একটা একটা করে পূরণ করো — সব তোমার নিজের account-এ হবে, সব হলে বট নিজে নিজেই চালু হয়ে যাবে

⬜

ধাপ ১: GitHub-এ একটা খালি repo বানাও

বটটা তোমার নিজের GitHub account-এর একটা repo-তে থাকবে। নিচের লিংকে গিয়ে খালি repo বানাও, তারপর repo-র নামটা এখানে লেখো।

🔗 এখানে গিয়ে repo বানাও
repo বানানোর সময় কী করবে?
  1. Repository name: blog-bot লেখো
  2. Private বেছে নাও
  3. আর কিছু টিক দিও না — একদম খালি রাখো
  4. Create repository চাপো
⬜

ধাপ ২: GitHub Token

অ্যাপটা তোমার হয়ে repo-তে ফাইল আর সেটিং বসাবে — তার জন্য এই token লাগে। শুধু তোমার এই browser-এই থাকবে। বসালেই নিজে নিজে যাচাই হয়ে যাবে।

🔗 টোকেন নেই? এখানে গিয়ে বানাও
টোকেন বানানোর সময় কী কী টিক দেবে?
  1. Token name: যেকোনো নাম (যেমন Bot Setup)
  2. Expiration: 1 year বা No expiration
  3. Repository access → Only select repositories → ধাপ ১-এর repo-টা বেছে নাও
  4. Permissions → Repository permissions: Actions: Read and write, Contents: Read and write, Secrets: Read and write, Workflows: Read and write
  5. Generate token → token-টা কপি করে এখানে বসাও
⬜

ধাপ ৩: Gemini API Key

বট এই key দিয়ে খবর rewrite করে। তোমার নিজের key বসাও — বসালেই নিজে নিজে যাচাই হয়ে যাবে।

🔗 Key নেই? এখানে গিয়ে বানাও (Create API key)
⬜

ধাপ ৪: Pixabay API Key (না দিলেও চলবে)

ছবি খোঁজার backup হিসেবে লাগে। না থাকলে এই ধাপ এড়িয়ে যাও।

🔗 Key কোথায় পাবে? এই পেজে লগইন করলেই key লেখা দেখবে
⬜

ধাপ ৫: Google Cloud Client

বট যাতে তোমার Blogger-এ পোস্ট করতে পারে, তার জন্য তোমার নিজের Google Cloud-এ একটা ছোট্ট client লাগে। একবারই করতে হয় — নিচের ধাপগুলো একে একে করো।

কীভাবে বানাবে — ধাপে ধাপে
  1. এখানে গিয়ে একটা Project বানাও — নাম যেকোনো (যেমন My Blog Bot)
  2. এখানে গিয়ে Blogger API চালু করো — উপরে তোমার project-টা বেছে নিয়ে Enable চাপো
  3. Consent screen-এ যাও — External বেছে নিয়ে নাম আর তোমার email দাও, শেষ পর্যন্ত গিয়ে Publish app চাপো
  4. Credentials পেজে যাও — Create Credentials → OAuth client ID → Web application
  5. Authorized JavaScript origins-এ হুবহু এটা বসাও:

⬜

ধাপ ৬: কোন ব্লগে পোস্ট হবে?

নিচের বোতামে Google দিয়ে লগইন করলে তোমার ব্লগের তালিকা আসবে — একটা বেছে নিলেই হবে। যেই Google account-এ ব্লগটা আছে, সেটা দিয়েই লগইন করবে।

⬜

ধাপ ৭: Blogger-এ পোস্টের অনুমতি

শেষ ধাপ। নিচের বোতামে চাপ দিলে Google-এর পেজ খুলবে — ধাপ ৬-এ যে account দিয়ে লগইন করেছিলে সেটাই বেছে নিয়ে Allow / অনুমতি দাও চাপবে। তাহলেই এখানে ফিরে আসবে, আর বট নিজে নিজেই চালু হয়ে যাবে।

🚀 বট চালু করা

সব ধাপ ✅ হলেই বট নিজে নিজে চালু হয়ে যাবে — আলাদা করে কিছু চাপতে হবে না। কোনো কারণে না হলে নিচের বোতামটা চাপলেই আবার চেষ্টা হবে।
