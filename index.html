🤖 ব্লগ বট সেটআপ

একটা একটা করে পূরণ করো — সব হলে বট নিজে নিজেই চালু হয়ে যাবে

⬜

ধাপ ১: GitHub Token

এটা লাগবে বটের সেটিং বসানোর জন্য। শুধু তোমার এই ফোনেই থাকবে — কোথাও পাঠানো হবে না। বসালেই নিজে নিজে যাচাই হয়ে যাবে।

🔗 টোকেন নেই? এখানে গিয়ে বানাও
টোকেন বানানোর সময় কী কী টিক দেবে?
  1. Token name: যেকোনো নাম দাও (যেমন Bot Setup)
  2. Expiration: 1 year বা No expiration
  3. Repository access → Only select repositories → blog-bot বেছে নাও
  4. Permissions → Repository permissions-এ টিক দাও: Actions: Read and write, Secrets: Read and write, Workflows: Read and write
  5. নিচে Generate token চাপো → token-টা কপি করে এখানে বসাও
⬜

ধাপ ২: Gemini API Key

বট এই key দিয়ে খবর rewrite করে। বসালেই নিজে নিজে যাচাই হয়ে যাবে।

🔗 Key নেই? এখানে গিয়ে বানাও (Create API key)
⬜

ধাপ ৩: Pixabay API Key (না দিলেও চলবে)

ছবি খোঁজার backup হিসেবে লাগে। না থাকলে এই ধাপ এড়িয়ে যাও।

🔗 Key কোথায় পাবে? এই পেজে লগইন করলেই key লেখা দেখবে
⬜

ধাপ ৪: কোন ব্লগে পোস্ট হবে?

নিচের বোতামে Google দিয়ে লগইন করলে তোমার ব্লগের তালিকা আসবে — সেখান থেকে একটা বেছে নিলেই হবে। যেই Google account-এ ব্লগটা আছে, সেটা দিয়েই লগইন করবে।

⬜

ধাপ ৫: Blogger-এ পোস্টের অনুমতি

শেষ ধাপ। নিচের বোতামে চাপ দিলে Google-এর পেজ খুলবে — ধাপ ৪-এ যে account দিয়ে লগইন করেছিলে সেটাই বেছে নিয়ে Allow / অনুমতি দাও চাপবে। তাহলেই এখানে ফিরে আসবে, আর বট নিজে নিজেই চালু হয়ে যাবে।

🚀 বট চালু করা

সব ধাপ ✅ হলেই বট নিজে নিজে চালু হয়ে যাবে — আলাদা করে কিছু চাপতে হবে না। কোনো কারণে না হলে নিচের বোতামটা চাপলেই আবার চেষ্টা হবে।

তোমার token আর key শুধু এই ফোনের browser-এ থাকে।
বটের secret GitHub-এর নিরাপদ ঘরে বসে — এখানে কিছু লেখা থাকে না।
